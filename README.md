## Описание
Данный репозиторий содержит два скрипта: `cloud_1.py` и `cloud_2.py`.  
- `cloud_1.py` выполняет обработку списка чисел: находит четные, максимум, минимум и сортирует список.  
- `cloud_2.py` использует Selenium для автоматизации тестирования веб-страницы (открытие, проверка заголовка, клик по ссылке, проверка редиректа).

---

## Зависимости
### Для `cloud_1.py`:
- **Python** версии 3.7 или выше (стандартная библиотека).

### Для `cloud_2.py`:
- **Python** версии 3.7 или выше.
- **Selenium** (установить через `pip install selenium`).
- **Chrome браузер** и **ChromeDriver** (версия драйвера должна совпадать с версией браузера).
- **Пакеты**: `selenium` (уже указан выше).

---

## Как запустить

### `cloud_1.py`
1. Убедитесь, что Python установлен и добавлен в переменные окружения.
2. Запустите скрипт через терминал:
   ```bash
   python cloud_1.py
   ```
3. Введите числа через запятую (например: `1, 2, 3, 4, 5`).

---

### `cloud_2.py`
1. Установите зависимости:
   ```bash
   pip install selenium
   ```
2. Убедитесь, что **Chrome** и **ChromeDriver** установлены и совместимы.
3. Запустите скрипт:
   ```bash
   python cloud_2.py
   ```
4. Скрипт автоматически откроет браузер, выполнит тесты и закроет его.

---

## Примечания
- Для `cloud_2.py`:
  - Если URL или ожидаемые параметры отличаются от примера, измените переменные в коде (`url`, `expected_title`, `expected_redirect_url`).
  - Убедитесь, что ChromeDriver добавлен в системный путь или укажите путь к нему явно в коде (если требуется).
